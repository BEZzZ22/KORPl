# Dota-тренер для Telegram

Бот разбирает матчи Dota 2: ставит оценки по разделам, находит конкретные ошибки с таймингами
и даёт советы, над чем работать. Данные берёт из OpenDota. Если задан ключ Anthropic,
Claude дополнительно пишет разбор как тренер.

## Что анализирует

| Раздел | Что проверяется |
|---|---|
| Линия | ластхиты и денаи к 10:00, нетворс против оппонента по линии, смерти на линии |
| Фарм | GPM и ластхиты относительно игроков на том же герое, простои в фарме, доля леса, урон по вышкам |
| Драки | участие в убийствах, пропущенные драки, урон по героям, слитое преимущество |
| Выживание | смерти в одиночку вне драк, время в таверне, потерянное золото |
| Убийцы | чем каждый убийца бил (по скиллам и типу урона), контроль, механики героя и что взять против него |
| Предметы | тайминг первого ключевого предмета, сапоги, ТП, защита от полученного типа урона |
| Видение | обсы, сентри, снесённые варды, стаки, смоки, руны на миде |

Кроме этого:
- **Про-сборки.** Для героя игрока берётся статистика предметов из про-матчей OpenDota. Контр-предметы,
  BKB и т.п. советуются, только если их реально собирают на этом герое; сборка сравнивается с про-сборкой.
- **Фазы игры.** Линия, мидгейм и лейт разбираются отдельно: убийства, смерти, фарм, нетворс против оппонента.
- **Хронология.** Ключевые моменты по минутам: смерти (в драке или в одиночку), первое убийство,
  крупные предметы, пропущенные драки, выкупы, самые сильные провалы и рывки команды.
- **Живой текст.** Все формулировки лежат в `docs/texts.json`, на каждую ситуацию несколько вариантов.

## Приложение в Телеграме

В папке `docs/` лежит Telegram Mini App: тот же разбор, но с вкладками, графиками и картинками
предметов. Приложение работает прямо в браузере Телеграма и берёт данные из OpenDota, свой сервер ему не нужен.

1. GitHub → Settings → Pages → Source: Deploy from a branch, папка `/docs`.
2. Впиши адрес в `.env`: `WEBAPP_URL=https://<ник>.github.io/KORPl`
3. Перезапусти бота: у чата появится кнопка «Приложение», а под каждым разбором кнопка «Открыть в приложении».

Движок разбора один — `docs/engine.js`. Приложение использует его напрямую, бот — через Node (`engine_cli.mjs`),
поэтому выводы в чате и в приложении всегда совпадают.

## Нормы по рангам

`docs/rank_norms.json` — процентили ключевых показателей (крипы к 10:00, GPM, смерти, участие в драках, обсы,
тайминг первого предмета и т.д.) для каждого ранга от Рекрута до Титана и каждой роли. Посчитаны по ~250 разобранным
рейтинговым матчам All Pick из OpenDota и сглажены по соседним рангам. Игрок оценивается относительно своего ранга
и роли: 26 крипов к 10:00 у керри-Титана — провал (хуже ~93% керри его ранга), а у Рекрута — ниже среднего.

## Запуск

Нужны Python 3.11+ и Node.js 18+: логика разбора живёт в `docs/engine.js`, бот вызывает её через `engine_cli.mjs`.

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env             # и впиши BOT_TOKEN от @BotFather
python bot.py
```

Тесты: `pip install pytest && pytest tests`

## Команды

- `/me <Friend ID>` — привязать аккаунт Доты
- `/last` — разобрать последний матч
- `/recent` — выбрать один из последних 5 матчей
- ID матча или ссылка с OpenDota, Dotabuff, Stratz — разобрать конкретный матч

В настройках Доты должна быть включена публичная статистика матчей, иначе OpenDota не увидит игры.

## Безопасность

- Токены только в `.env`, файл не попадает в git.
- Бот отвечает только в личных сообщениях.
- Антифлуд: не чаще сообщения в секунду и разбора в 10 секунд от одного человека, один разбор за раз.
- Дневной лимит ИИ-разборов на пользователя, чтобы никто не сжёг деньги на API.
- Весь ввод проверяется, текст из API и ответы ИИ экранируются перед отправкой.
- Запросы к OpenDota ограничены по параллельности, с повторами и кешем матчей.
