# watch — смотрим ролики

Claude не видит видео напрямую, поэтому ролик превращаем в кадры + текст. Всё бесплатно и локально: yt-dlp, ffmpeg, faster-whisper.

## Шаги

1. Зависимости (один раз за сессию, тихо):
   `pip install -q -U yt-dlp faster-whisper` и проверить `ffmpeg -version`. Нет ffmpeg: Linux `apt-get install -y ffmpeg`, Windows `winget install ffmpeg`.
2. Запуск:
   `python .claude/skills/watch/watch.py "<ссылка>"`
   Скрипт печатает путь к `report.md`. Полезные флаги:
   - `--every 1` — кадр каждую секунду (для коротких рилсов и разбора монтажа); по умолчанию 2 с + смены сцен.
   - `--max-frames 60` — потолок кадров; на длинных роликах шаг растягивается сам.
   - `--whisper tiny|base|small` — модель речи (по умолчанию base; tiny быстрее, small точнее). `--lang ru` — если язык известен.
   - `--cookies cookies.txt` или переменная `WATCH_COOKIES` — если площадка просит вход.
   - `--no-audio` — без расшифровки. Вместо ссылки можно дать путь к файлу.
3. Прочитать `report.md`: метаданные, описание, список кадров с таймкодами и речь с таймкодами.
4. Посмотреть кадры через Read. Короткий ролик (до минуты) — все кадры; длинный — сначала каждый 3-4-й, потом гуще вокруг важных мест из текста.
5. Ответить по сути вопроса: что происходит по таймкодам, хук первых 3 секунд, текст на экране, темп монтажа, призыв в конце. Не выдумывать то, чего нет на кадрах или в тексте.

## Откуда берётся речь

Сначала субтитры площадки (ручные или авто, ru/en), если их нет — локальный whisper. Модель качается с Hugging Face при первом запуске (~150 МБ для base).

## Если не качается

- `Sign in to confirm you're not a bot` (YouTube) и вообще требование входа: нужен cookies.txt. В браузере, где залогинен, расширение «Get cookies.txt LOCALLY» → экспорт для сайта → путь в `--cookies`. Cookies — секрет: не коммитить, не класть в project-files.
- В облачной сессии Claude: YouTube с облачных IP почти всегда упирается в капчу Гугла, тут без cookies никак. Instagram без логина отдаёт рилсы. TikTok и Instagram качают видео с CDN, у которых меняется имя хоста; если прокси отвечает 403, хост надо добавить в разрешённые в настройках облачного окружения (или открыть сеть целиком).
- На своём компе (Claude Code локально или Remote Control) всё это обычно работает сразу.
