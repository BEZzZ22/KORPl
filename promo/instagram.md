# Инстаграм: как подключить автопостинг рилсов

Идея та же, что с Телеграмом: ассистент делает ролики и очередь, а публикует GitHub Actions по расписанию через официальный API Meta. Сам «сидеть в аккаунте» ассистент не может (нет браузера с твоей сессией и не нужно), и пароль от Инстаграма никому давать не надо.

## Что нужно сделать тебе (около 30-40 минут, один раз)

1. **Аккаунт.** Свой или новый Инстаграм, переключить в «Профессиональный» (Настройки → Тип аккаунта → Креатор или Бизнес). Обычный личный аккаунт через API постить не умеет.
2. **Meta for Developers.** Зайди на developers.facebook.com под своим Фейсбуком, нажми «Мои приложения → Создать приложение» (тип «Другое» / «Бизнес»), назови как хочешь, например `DotaRazborReels`.
3. **Продукт.** В приложении добавь продукт **Instagram** (API с входом через Instagram). В нём включи `instagram_business_basic` и `instagram_business_content_publish`.
4. **Роль.** В «Роли приложения → Тестировщики» добавь свой Инстаграм-аккаунт и прими приглашение в Инстаграме (Настройки → Приложения и сайты → Приглашения тестеров). Пока приложение в режиме разработки, оно работает только для аккаунтов с ролью, и этого для своего аккаунта достаточно: проверка Meta не нужна.
5. **Токен.** В разделе Instagram → «Генерация токенов доступа» нажми «Сгенерировать токен» для своего аккаунта. Получишь длинный токен (живёт 60 дней, потом его надо обновить) и ID аккаунта (IG user id).
6. **Секреты GitHub** (`https://github.com/bezzz22/korpl/settings/secrets/actions`): `IG_USER_ID` и `IG_TOKEN`. В чат токен не кидай.
7. Напиши ассистенту «инста готова».

## Что делает ассистент

- **Ролики.** Делаю вертикальные рилсы 9:16 с настоящей записью мини-аппа (Playwright + ffmpeg): заголовок, субтитры, музыка не нужна (в Инстаграме со звуком из библиотеки не публикуется через API, можно без звука с субтитрами). Сценарии: «кинул Match ID, вот разбор», «Аегис крутится», «что собирать против пика», «где я умираю». Хранить файлы будем в GitHub Pages, чтобы у ролика был публичный https-адрес (так требует API).
- **Очередь и публикация.** Файл `promo/ig_queue.json` и воркфлоу по расписанию: создаёт контейнер `POST /{ig-user-id}/media` с `media_type=REELS` и `video_url`, ждёт обработки и публикует `POST /{ig-user-id}/media_publish`. Подписи с хештегами из `promo/README.md`.
- **Ритм.** 1 рилс в день или через день в разное время. Чаще смысла нет: Инстаграм душит одинаковые ролики.
- **Токен.** Воркфлоу сам обновляет его раз в месяц (`refresh_access_token`).

## Чего не делаем (чтобы не словить бан)

- Никаких скриптов, которые заходят по логину и паролю или сессии, лайкают, подписываются и пишут в директ (instagrapi и похожее). За это Инстаграм банит аккаунты. Только официальный API.
- Не гоним один и тот же ролик по 10 раз. Каждый должен отличаться темой и кадрами.
- Купленные подписчики не нужны и вредят охвату.

## Другие площадки

- **YouTube Shorts:** официальный API есть (YouTube Data API v3, OAuth). Но у нового проекта в Google ролики с загрузки по API бывают «приватными», пока проект не пройдёт аудит. Можно сначала загружать вручную.
- **TikTok:** Content Posting API требует аудит приложения, до него ролики только в черновиках/приватно.
