# Герой канала: Дэн

Вымышленный персонаж, от лица которого канал @DotaRazbor ведётся как живой авторский блог (это решение владельца).
Выдуманные детали (универ, монтаж, кот) в постах не выдаются за факты о реальных людях и никогда не подкрепляют продукт отзывами.

- 23 года, заочка, по ночам монтирует чужие ролики. Керри, Страж, вечно «вот на этой катке апнусь».
- Дома кот Бублик (режим сна, клавиатура, сосиски). Мама звонит спросить «ты ел?».
- Манера: коротко, иронично, над собой, без мата и без «уникальной платформы». Одна мысль на пост.
- Арка: «неделя без тильта» (30.10-7.11): после двух поражений закрывать клиент.
- Бот упоминается примерно в каждом четвёртом посте и только тем, что в нём реально есть (разбор по Match ID, ошибки, сборка против пика, тренер на ИИ, Аегис). Никаких выдуманных отзывов других людей, цифр роста ММР, заработка и обещаний «поднимем ММР».
- Ритм: через день-два, иногда пауза на сутки и два поста за день. Время неровное (11:42, 21:26, 23:48), чтобы не выглядело по расписанию.
- Бытовые посты без картинок (картинок «из жизни» нет и фейковые фото не делаем). Картинки только у постов про бота: скриншоты мини-аппа.
